DS212 — Object-Oriented Programming#

Course Information Details

Course Title Object-Oriented Programming Course Code DS212 Department Data Science Department, CITC Year & Semester Second Year, 1st Semester, AY 2026–2027 Credits 3 units Weekly Contact Hours 2 hours Lecture + 3 hours Laboratory Prerequisites DS121, DS123 Co-requisite None

Course Description#

Object-Oriented Programming introduces programming from an object-oriented perspective and develops the competencies needed to design maintainable software for data science applications. The course covers classes and objects, abstraction, encapsulation, inheritance, polymorphism, special methods and operator overloading, exceptions, advanced class features, packaging, testing, distribution, documentation, and project organization.

Through lectures and guided laboratory work, students design, implement, test, debug, package, and present object-oriented Python applications using modern software engineering and design principles.

Course Outcomes#

Outcome Description

CO1 Explain and apply object-oriented programming fundamentals using classes, objects, abstraction, encapsulation, inheritance, polymorphism, and special methods.

CO2 Test, verify, debug, document, and organize object-oriented programs using exceptions, decorators, packages, and appropriate software engineering practices.

CO3 Design, implement, package, and present a tested object-oriented Python application that addresses a defined real-world problem.#

Ethical Use of AI#

Guideline Policy

Permitted Use AI tools may assist with brainstorming, improving writing clarity, or supporting data analysis.

Disclosure AI use must be properly disclosed in references or through an AI acknowledgement.

Student Responsibility Students are responsible for verifying the accuracy, originality, and ethical integrity of AI-assisted outputs.

Prohibited Use AI must not generate entire assignments, research papers, or examination answers.

Academic Integrity Plagiarism, data fabrication, and over-reliance on AI without critical evaluation are treated as academic integrity violations.#
